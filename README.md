# TEM/SEM Image Segmentation Data Pipeline

This repository contains a reproducible ETL (Extract, Transform, Load) pipeline for my electron microscopy image segmentation project. The pipeline retrieves three publicly available microscopy datasets, organizes the raw image and segmentation-label data, and creates a unified SQLite database for later image-processing and machine-learning analysis.

The long-term goal of the project is to develop and evaluate methods for nanoparticle segmentation and particle-size analysis from TEM/SEM images.

## Datasets

The database combines data from three microscopy datasets.

### 1. EMPS Dataset

The EMPS dataset contains heterogeneous TEM and SEM images with manually annotated particle segmentation maps.

- Images used: 465
- Training images: 366
- Test images: 99
- Image format: PNG
- Segmentation maps: PNG instance masks
- Source: https://github.com/by256/emps

The original train/test split supplied with the dataset is preserved.

### 2. HRTEM Generalization Dataset

The HRTEM Generalization dataset contains high-resolution TEM images of different nanoparticle materials.

For reproducibility and manageable data size, this project uses a deterministic 30-image subset:

- Ag: 10 images
- Au: 15 images
- CdSe: 5 images
- Total: 30 images

The subset is selected using a fixed random seed (`random_state=42`), so repeated runs select the same records.

The original source-folder hierarchy is retained because some filenames occur in more than one source folder.

Sources:

- https://doi.org/10.7941/D1SP93
- https://portal.nersc.gov/project/m3795/hrtem-generalization/
- https://github.com/ScottLabUCB/HRTEM-Generalization

### 3. Co3O4 Dataset

The Co3O4 dataset contains microscopy images and corresponding one-hot encoded segmentation labels stored in HDF5 files.

- Images used: 256
- Image dimensions: 512 x 512 pixels
- Image file: `training_images.h5`
- Label file: `training_labels.h5`
- Source: https://zenodo.org/records/14927582

## Unified Database

The ETL pipeline creates:

```text
Data/Database/microscopy.db
```

The SQLite database contains one unified `images` table containing image, label, dataset, and microscopy metadata.

Important fields include:

- unique image ID
- source dataset
- original filename
- image path
- label path
- image width and height
- image and label format
- label type
- material
- nominal particle size
- particle shape
- support material
- instrument
- electron dosage
- pixel size
- source folder
- train/test split

Expected database record counts are:

| Dataset | Records |
|---|---:|
| EMPS | 465 |
| HRTEM | 30 |
| Co3O4 | 256 |
| **Total** | **751** |

## Running the ETL Pipeline

### Requirements

The reproducible workflow uses:

- Git
- Just
- Podman

Python and the required Python packages are installed inside the container defined by the `Containerfile`.

### Run

From the repository root, execute:

```bash
just
```

The `Justfile` builds the container and runs the Makefile inside it.

The workflow is:

```text
Justfile
   |
   v
Containerfile / Podman
   |
   v
Makefile
   |
   +--> download_EMPS.py
   |
   +--> download_HRTEM.py --demo
   |
   +--> download_Co3O4.py
   |
   v
create_database.py
   |
   v
Data/Database/microscopy.db
```

The download scripts check whether the required data already exist before downloading them. Therefore, rerunning the pipeline does not intentionally duplicate the raw datasets.

The database-generation step recreates the SQLite database deterministically so that repeated runs produce the expected 751 database records.

## ETL Process

### Extract

The download scripts retrieve or verify the required source datasets:

```text
Scripts/download_EMPS.py
Scripts/download_HRTEM.py
Scripts/download_Co3O4.py
```

### Transform

Dataset-specific information is standardized into a common representation. This includes file paths, label types, microscopy metadata, material information, image dimensions, physical scale information where available, and dataset split information.

### Load

`Scripts/create_database.py` creates the unified SQLite database and loads records from all three datasets.

A successful run should report:

```text
EMPS  = 465
HRTEM = 30
Co3O4 = 256
TOTAL = 751
```

## Reproducibility

The pipeline is designed so that the database can be recreated from the repository rather than storing the generated database in Git.

The following are therefore excluded using `.gitignore`:

```text
.venv/
Data/Raw/
Data/Database/*.db
```

The small HRTEM metadata file required to deterministically select the demo subset is tracked under:

```text
Data/Metadata/Dataset_metadata.csv
```

## Project Goal

The database produced by this ETL pipeline will serve as the data foundation for subsequent stages of the semester project, including:

1. microscopy image preprocessing,
2. nanoparticle segmentation,
3. comparison with traditional image-processing baselines,
4. U-Net-based semantic segmentation,
5. segmentation evaluation using metrics such as Dice coefficient and Intersection over Union (IoU), and
6. particle-size and morphology analysis.

This repository currently focuses on the reproducible data acquisition and database-generation stage of the project.
